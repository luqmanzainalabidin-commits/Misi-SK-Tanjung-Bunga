MISI 14 NILAI: SEHARI DI SK TANJUNG BUNGA — V1

Cara jalankan:
1. Paling mudah untuk ujian komputer: jalankan server tempatan dalam folder ini.
   Windows/Mac/Linux dengan Python: python -m http.server 8080
   Kemudian buka http://localhost:8080
2. Untuk telefon/tablet: upload keseluruhan folder ini ke hosting web HTTPS.
3. PWA/offline akan aktif selepas lawatan pertama melalui HTTPS atau localhost.

Kawalan:
- Telefon/tablet: D-pad + butang Interaksi.
- Komputer: Arrow/WASD untuk bergerak, E/Space untuk interaksi.

Data:
- Kemajuan game dan Top 5 leaderboard disimpan dalam browser/peranti (localStorage).
- Tiada data dihantar ke server.

Audio:
- Muzik retro dan SFX dijana secara ringan menggunakan Web Audio API, jadi tiada fail muzik berat.
